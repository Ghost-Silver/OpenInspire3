# OpenInspire3

开源神经网络飞控无人机平台。用神经网络控制真实动力学意义下的飞行器，并以
[CTorch](https://github.com/ShengFlow/CTorch) 作为训练与仿真后端。

目标是把商用飞控软件的高昂成本省掉，为开源社区提供一套可复现、可扩展的低成本方案。

### 实测（定点悬停）

任务：从 (0,0,0) 飞抵目标点并保持。被控对象质量 1 kg、重力 9.81 m/s²、
阻力系数 0.3、推力上限 20 N（推重比约 2:1）。

| 控制器 | 稳态误差 | 收敛时间 | 峰值推力 |
|--------|----------|----------|----------|
| PID（解析最优） | 0.0002 m | 1.27 s | 10.66 N |
| ContinuousPPO（学习） | 0.1031 m | — | 13.41 N |

学习型控制器的训练曲线（2000 回合，约 196 秒）：

| 指标 | 起始 | 结束 |
|------|------|------|
| 平均回合奖励 | −8.88 | −0.45 |
| 末端位置误差 | 2.02 m | 0.165 m |
| 到位率 | 0% | 80% |

**结论**：神经网络可以在真实动力学上从零学出可用控制律。PID 在该线性任务上仍是
解析最优（领先两个数量级）；学习型控制器的价值预期体现在更强非线性、感知一体化
与多机协同等 PID 难以解析建模的场景。

## 构建

需要 CMake ≥ 3.20 与支持 C++23 的编译器；首次构建会自动拉取 CTorch 子模块。

```bash
git submodule update --init --recursive
cmake -S . -B build -G Ninja
cmake --build build
```

## 设计要点

**控制器接口统一**。PID 与学习型控制器实现同一个 `Controller` 接口，输入状态与
期望位置、输出 NED 系合推力，中间不做任何坐标或单位变换。因此解析基线先行跑通，
可以把被控对象与接口本身的正确性固定下来——后续学习型控制器表现不佳时，可以
排除动力学与接口的嫌疑。

**控制频率与仿真频率解耦**。仿真以 1 kHz 积分以保数值精度，控制按 100 Hz 执行，
对应真实飞控的内外环分层，同时把 RL 的步数减少一个量级。

**动作以悬停推力为中心**。策略输出的是相对悬停推力的修正量，而不必从头学出
`m·g` 这个已知常量。

**奖励只用有界的控制代价**。位置误差、速度、推力偏离悬停量的加权平方和取负，
三项都有界，不存在可以无限累积的正向项，避免出现「刷分」式退化解。

## 已知问题

- 程序在评估结束后退出时会出现 `recursive_mutex lock failed`（CTorch 静态对象
  析构顺序问题），不影响训练与评估结果。
- 当前为 3 自由度质点模型，推力方向可任意指定；真实无人机需靠倾斜机身产生水平
  分力，6 自由度与姿态环尚未实现。
- `core/rl/Environment` 是早期体素搜索环境，动作映射为固定加速度、不含质量与
  推力约束，与 `PhysicsEngine` 尚未打通。

## 路线图

1. **课程学习**：逐步扩大目标与初始位置范围，提升策略泛化
2. **6 自由度**：加入姿态四元数与角速度，使「飞控」名实相符
3. **传感器模型**：IMU / GPS 噪声、延迟、漂移
4. **抗扰与轨迹跟踪**：风扰、时变参考轨迹
5. **多机协同**：共享观测下的协同搜索
6. **硬件抽象层**：面向真实飞控硬件的接口
