# 位置滤波器：从固定增益 α-β 到卡尔曼

本文件记录位置滤波器升级的动机、设计、参数标定过程与对照数据。

## 一、动机：固定增益的结构性局限

原实现是固定增益 α-β 滤波器，校正步为：

```
_pos += α · r
_vel += (β/dt) · r     其中 β = α²/(2−α)，临界阻尼约束
```

α 默认 0.35。这个值是按「位置反馈滞后」调的（见 `EstimatorConfig` 注释：
α=0.35 时速度估计误差 0.33 m/s，比 α=0.05 时的 0.032 m/s 大一个量级，
但闭环性能反而好一倍 —— 说明速度噪声会被控制环滤掉，而位置滞后是纯相位损失）。

问题出在**增益是常数**：

1. **换传感器就要重调**。α=0.35 是针对光流级噪声（σ≈0.05 m）调的。
   GPS 级噪声（σ≈0.30 m）下，速度校正增益 `β/dt ≈ 7.4 /s` 会把 0.3 m 的
   噪声直接变成约 2.2 m/s 的速度脉冲，控制器 `kd=3` 再放大即发散。

2. **只能靠死区补救**。P5 为此引入了 `pos_residual_deadzone`（仅作用于速度校正）。
   实测有效（GPS 级噪声下高度偏差从 46.04 m 降到 3.45 m），但死区本质上是
   给「增益失配」打的补丁：它靠**丢弃小残差**来抑制噪声，代价是引入稳态偏差，
   且阈值（0.15 m）需要手工标定。

α-β 滤波器在理论上本就是**稳态卡尔曼的特例** —— 它缺的正是「增益随噪声自适应」
这一能力。因此升级方向明确：改用位置-速度卡尔曼滤波。

## 二、设计

每轴独立的 2×2 卡尔曼，状态 `[p, v]`：

```
预测（updateImu，每步）：
  p ← p + v·dt + ½·a·dt²
  v ← v + a·dt
  P ← F·P·Fᵀ + Q,   F = [[1, dt], [0, 1]]

更新（updatePosition，每 10 步）：
  y = z − p                     新息
  S = p_pp + R                  新息方差
  K = [p_pp/S, p_pv/S]ᵀ         增益
  p += K₀·y,  v += K₁·y
  P ← (I − K·H)·P
```

过程噪声按连续白噪声加速度模型展开（q 为加速度不确定度）：

```
Q_pp = q²·dt⁴/4,  Q_pv = q²·dt³/2,  Q_vv = q²·dt²
```

三轴解耦：位置量测按轴独立；IMU 加速度虽经姿态旋转产生轴间耦合，
但耦合项远小于各轴自身不确定度，解耦显著降低复杂度而精度损失可忽略。

## 三、参数标定：q 为什么是 100

`kalman_accel_noise` 的物理含义是「预积分所用加速度的可信度」。
若按加速度计本身的噪声量级（约 0.08 m/s²）取值，闭环**直接发散**。

原因是**预积分误差并非白噪声**：姿态误差经重力投影产生虚假加速度、
陀螺偏置积分、控制推力响应滞后等，都表现为长相关误差，其增长速度远快于
「白噪声加速度」模型的假设。标准解法（加速度偏置随机游走模型）会引入额外
状态与调参维度，故这里用增大的过程噪声补偿模型失配。

标定实验扫描 q 从 0.1 到 500，覆盖光流级与 GPS 级两种场景：

| q | 光流级 σ=0.05 高度偏差 | GPS 级 σ=0.30 高度偏差 |
|---|---|---|
| 0.1 | 45.03 m（发散） | — |
| 0.5 | 48.97 m（发散） | — |
| 2.0 | 37.14 m | — |
| 5.0 | 5.66 m | — |
| 10 | 0.04 m | 46.78 m（发散） |
| 20 | 0.01 m | 31.82 m |
| 50 | 0.01 m | 11.09 m |
| **100** | **0.03 m** | **0.25 m** |
| 200 | 0.11 m | 0.35 m |
| 500 | 0.53 m | 2.89 m |

两个方向都失败过：

- **q 过小**：滤波器过度信任预积分，速度估计失去量测校正而漂移，
  闭环发散。这与「预积分不可信所以应该少信它」的直觉相反 —— 问题不在
  信任度分配，而在于预积分误差是长相关的，白噪声模型无法描述。
- **q 过大**：等同不信任模型，退化为直接使用含噪量测。

100 是两种噪声水平下同时可用的区间。其等效位置增益（0.299）与经过验证的
α-β 增益（0.35）同量级，即「带宽匹配既有设计，同时获得噪声自适应性」。

## 四、对照结果

同一仿真、同一噪声种子，`PositionNonIdealClosedLoopTest` 的滤波器对照章节：

| 场景 | α-β + 死区 | 卡尔曼 | 结论 |
|---|---|---|---|
| 理想量测 | 0.00 m | 0.00 m | 相当 |
| 光流级 σ=0.05 | 0.07 m | **0.05 m** | 更优 |
| GPS 级 σ=0.30 | 3.51 m | **1.90 m** | 更优 |

卡尔曼的参数用法是「把该场景的实际 σ 告诉滤波器」，而非调参寻优后的值 ——
这正是它与 α-β 的区别：参数有物理含义，换传感器只需改一个数。

**卡尔曼路径完全不需要死区**（测试中 `pos_residual_deadzone` 保持 0.0）。

增益自适应性另有直接断言：同一份代码，仅改变告知的量测噪声，
位置增益必须随之下降。实测 σ=0.01 时增益 0.5485，σ=1.00 时 0.0772。
若增益不随 R 变化，说明协方差更新未生效，本模块的核心价值即不成立。

## 五、组合缺陷记录：协方差预测与 `trust_position` 的耦合

这是把两个各自正确的模块（本滤波器与 IMU 降级开关）组合后才暴露的问题，
属于「单个模块正确不能推出组合正确」的又一实例。

**症状**：关闭 `trust_position`（陀螺失效后的降级路径会这样做）后，卡尔曼增益
单调衰减。实测第 100→500 步位置增益由 0.326 掉到 0.030（近 11 倍），
滤波器对位置量测几乎失去响应 —— 即所谓「睡着」。

**根因**：协方差预测原先被嵌在预积分块 `if (_has_pos && _trust_position)` 内，
而量测更新在 `updatePosition` 中**独立执行**、不受该开关控制。两者的不对称导致
关闭预积分后协方差只减不增：预测步被跳过，更新步继续收缩协方差。

**修复**：把协方差预测移出条件块，仅要求 `_has_pos`。语义上也应如此 ——
不做位置预测时，我们对位置的把握只会更差，不确定度必须随时间增长，
而不是因量测更新而收缩。

**回归断言**：`PositionNonIdealClosedLoopTest` 新增一条断言，跑 200 步建立稳态后
关闭 `trust_position`、再跑 300 步，要求增益不低于稳态值的 80%。
量测按真实频率（100 Hz）注入 —— 若每步都给量测，增益会落到 0.06 附近，
偏离实际工况一个量级，那样的断言虽也能守住「不衰减」，但覆盖的是不真实的场景。

该断言的有效性经过反证：临时把协方差预测改回条件块内，断言立即失败
（增益 0.2995 → 0.0308，43/44），确认它不是恒真断言。

### 组合覆盖

`KalmanFaultCombinationTest`（15/15）在卡尔曼路径下完整验证三类故障的降级链路：

| 故障 | 卡尔曼路径姿态误差 | 决策 |
|---|---|---|
| 无故障 | 0.026° | Normal |
| 陀螺失效 | 0.394°（触地倾角 0.38°） | **EmergencyLand** |
| 加速度计失效 | 0.018°（维持 5.43 m） | **ReturnHome** |
| 加速度计偏置 | 0.213° | **Cautious** |

三条降级决策在卡尔曼路径下均正确，数值与 AlphaBeta 同量级（差异在噪声量级）。
测试同时包含「激励确认」断言（确认三类故障确实被检出），避免「没有激励
也算通过」。

## 六、接入方式与现状

`EstimatorConfig::pos_filter` 提供两种实现，**默认仍为 `AlphaBeta`**：

- 更换位置滤波器会改变所有依赖位置估计的闭环结果（本仓库 55 个测试），
  故与项目既有惯例一致（如 IMU 容错、位置死区），新路径以可选方式接入、
  默认关闭，待对照数据充分后再讨论是否切换默认值。
- 切换默认值属于改变全局行为，需要独立的回归验证与明确决策，不在本次改动范围。

启用方式：

```cpp
EstimatorConfig cfg;
cfg.pos_filter = PosFilterKind::Kalman;
cfg.kalman_pos_noise = 0.05;   // 该场景的位置量测标准差
// cfg.kalman_accel_noise 默认 100.0，除非有新的标定数据否则无需修改
```

## 七、已知限制

1. **q 是标定值而非推导值**。它补偿的是模型失配，物理意义间接。
   若更换动力学模型或控制参数，需重新标定。
2. **未验证的场景**：机动飞行（当前对照均为定点悬停 + 目标点切换）、
   量测丢失与恢复、多传感器切换（如 GPS 与光流的互补融合）。
3. **三轴解耦** 在大倾角机动的耦合项下未做误差评估。
4. **未包含 IMU 与量测的时间同步误差**，当前假设两者时间戳一致。
